## 검증

최종 환경(Streamlit 1.66.1, Pillow 13.0.0)에서 자동 테스트 **30개 통과**.

- 실제 함수에 대한 독립 측풍 공식/합집합 계산 대조, 정온·빈 자료·비정상값 검사.
- CSV 날짜/지점/단위/중복/충돌/크기/열 검증 및 원본 제외사유 보존 검사.
- API 오류·부분 실패·요청 시작시간·민감정보 비노출 검사.
- 생성 Excel XML에서 수식/자동 링크 부재 검사, 실제 DOCX의 실패 판정/확보율/방위 기준 검사.
- Streamlit AppTest로 초기 화면·API 키 입력창·모의 ASOS 분석·다운로드 3종 검사.
- 실제 로컬 서버의 상태 확인 주소와 시작 페이지 HTTP 200 확인.
- 설치 패키지 79개를 pip-audit로 대조한 최종 결과: 알려진 취약점 0개.
  초기 requirements 기반 검사가 빈 목록을 반환해 검사 범위를 수정했고, 실제 설치 경로의
  전체 패키지를 검사하여 Pillow 문제를 확인·수정한 뒤 재검사했다.

GitHub Actions에서 Python 3.12 테스트와 설치 환경의 패키지 취약점 검사를 실행한다.

사용자 의견에 따른 결과 유지·진행 안내·브라우저 키 저장의 후속 변경 및 최종 검증은
[USER_FEEDBACK.md](USER_FEEDBACK.md)에 기록했다. 브라우저 직접 저장은 사용자가 선택한
추가 저장 방식이며 서버 비밀키는 대상에서 제외한다.

## 남은 검증 경계

- 실제 API 인증키를 사용한 장기 ASOS 수집·Kakao 검색은 수행하지 않았다. 네트워크 실패와
  정상 응답 경로는 모의 데이터로 검증했다. 배포 전에 실제 계정 권한/할당량을 확인해야 한다.
- Docker 이미지를 실제로 빌드하거나 운영 Streamlit/Cloud Run 환경에 배포하지 않았다.
- 공개 방문자가 서버 공용 키로 계산을 요청할 수 있는 구조는 유지한다. 계정별 호출 한도·인증은
  배포 방식에 맞춰 별도 적용해야 한다. 위젯 비노출은 호출 권한 제어를 대신하지 않는다.
- ICAO/국내 기준의 최신 판본 적합성 인증은 수행하지 않았다. 10° 격자·3 kt 정온·
  세 허용치 합산 선정은 기존 분석 정책을 유지한다. 실제 시설계획에는 대표성·자기편각·항공기
  조건·입지 및 운영 조건의 별도 검토가 필요하다.
- 알려진 취약점 0개는 조회 시점 DB와 설치 환경 기준이며 모든 취약점 부재를 보장하지 않는다.
